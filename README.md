# Hebrew Voice Game — Android download

A Hebrew learning game for young children: letter tracing, counting, spelling,
balloons, stories and more, with recorded Hebrew voice. Works offline once installed.

**Download:** [hebrew-voice-game.apk](https://github.com/BarakEm/hebrew-voice-game-apk/releases/latest/download/hebrew-voice-game.apk)

## Installing on an Android phone or tablet
1. Open the link above on the phone or tablet and download the file.
2. Tap the downloaded file. If Android asks, allow installing apps from this source
   (your browser or Files app).
3. Tap **Install**.

New versions install over the old one; progress is kept.
